- **Monitoring, Reporting, and Verification (MRV)**

1. A concatenated Markdown document (the “CONTEXT”) that describes the biochar project, its audits, and any related information.
2. A JSON array containing multiple criteria/questions related to the same **topic, sub-topic, and risk factor**. Each JSON object has the following structure:

```json

  },
```

**Your Task**
  1. Check the `detail_level` field:


  3.  Carefully examine and analyze one by one the list of criteria/questions and their associated answers (`short_answer`, `long_answer`, `missing_or_contradictory_data`).

    * Derives information **explicitly** from the CONTEXT.
    * Includes **clearly stated assumptions** based on recognized standards (e.g., Puro, Verra, Riverse).
    * Assumptions are acceptable only if **explicitly** labeled as such and consistent with how the standard is typically applied.
  * An unfaithful (hallucinated) answer:
    * Contains details not mentioned or implied by the CONTEXT and not clearly justified by standard-based assumptions.
    * Contradicts the CONTEXT.
    * Fails to label or justify additional details as assumptions when they are not explicitly supported by the CONTEXT.
  5.  Return a Judgment for Each Entry in the JSON Array:
  • If an answer contains unsupported or contradicting information, mark it as a hallucination.
  • If an answer is consistent with the CONTEXT and/or includes validly labeled assumptions, mark it as not a hallucination.
  6.  Return the updated JSON array that contains all the criteria in the input JSON, do not return undone JSON array.
